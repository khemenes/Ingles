# Inglês com Claudio

App pessoal de estudo de inglês (trilha B1 → B2). Funciona no navegador, sem instalar nada.

## Como publicar (GitHub Pages)
1. No GitHub, abra o repositório e envie estes arquivos para a raiz dele: `index.html`, `.nojekyll`, a pasta `units` e este `README.md`.
2. Vá em **Settings → Pages**. Em **Source**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)**, e salve.
3. Depois de 1 a 2 minutos, o endereço aparece nessa mesma tela: `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Professor IA (chave gratuita do Gemini)
1. Abra https://aistudio.google.com/apikey, entre com a conta Google e crie uma chave.
2. No app, na tela **Início**, role até **Ajustes**, cole a chave e toque em **Salvar** e depois em **Testar conexão**.
3. A chave fica só no navegador desse aparelho. Cada aparelho precisa da sua. Nunca coloque a chave dentro dos arquivos do repositório.

Se o teste disser que o modelo não existe, troque os nomes nos campos de modelo (os nomes mudam com o tempo; veja a lista atual em https://ai.google.dev/gemini-api/docs/models).

## Progresso
O progresso fica salvo no navegador. Em **Ajustes**, use **Exportar progresso** para baixar um backup e **Importar progresso** para restaurar em outro aparelho. Limpar os dados do navegador apaga o progresso, por isso exporte de vez em quando.
